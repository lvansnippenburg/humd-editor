            Editor

            Use MacOS built in spell check.

            Auto-save clears undo history after each save. Undo/redo will not work across save boundaries.

            As you type, replace straight quotes with curly ones (‘ ’ “ ”, UK style). Put a backslash before a quote (\') to keep it straight; quotes inside `code` are left alone.

            Renders the preview using the system Pandoc installation instead of the built-in renderer. Pandoc produces more accurate output for complex documents but requires Pandoc to be installed.

            Citations

            Bibliography file (CSL JSON or BibTeX) and CSL style for formatting citations. Use \@ in your text to cite a reference. Requires Zotero and the Better Bibtex extension for Zotero.

            None selected
            None selected (defaults to APA)

            Export

            Configure options for exporting documents to Microsoft Word (.docx) format using Pandoc.

            None selected

            Proofreading

            Proofread the document (or a selection) with Google Gemini (remote) or a local Ollama service. Settings are stored locally; with Ollama your text never leaves your machine.

            Get a free API key at aistudio.google.com/apikey. The key is sent only to Google when you proofread.

            Requires ollama serve running locally and a pulled model (e.g. ollama pull llama3.1).

            Custom CSS applied to the rendered content. Use standard CSS syntax.
