# humd-editor

Before using, copying, or modifying this code: **read the [LICENSE.md](LICENSE.md) file.**

A Markdown editor for the humanities. Includes inline footnotes and integration with Zotero (with a little help of BetterBibTex). It is not perfect, but it's the best possible solution if you want to use a plain text format for your writings.

## Keyboard shortcuts

On macOS use **⌘ (Cmd)**; on other platforms use **Ctrl**.

### General

| Shortcut | Action |
| --- | --- |
| `⌘S` | Save the current file |
| `⌘E` | Toggle the preview pane |

### Editing

| Shortcut | Action |
| --- | --- |
| `⌘Z` | Undo |
| `⌘Y` or `⌘⇧Z` | Redo |
| `⌘B` | Bold the selection (`**…**`) |
| `⌘I` | Italicise the selection (`_…_`) |
| `⌘1` | Make the line a level-1 heading (`# `) |
| `⌘2` | Make the line a level-2 heading (`## `) |
| `⌘3` | Make the line a level-3 heading (`### `) |
| `\@` | Open the Zotero (Better BibTeX) citation picker |

### Autocomplete (while the suggestion popup is open)

Typing `[[` suggests note names; typing `#` suggests existing tags.

| Shortcut | Action |
| --- | --- |
| `↑` / `↓` | Move through the suggestions |
| `Enter` or `Tab` | Accept the highlighted suggestion |
| `Esc` | Dismiss the popup |

### Dialogs and inline inputs

| Shortcut | Action |
| --- | --- |
| `Enter` | Confirm (rename, new file) |
| `Esc` | Cancel / close (rename, new file, settings) |
